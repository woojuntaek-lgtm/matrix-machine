# 행렬 변환 기계

행렬은 숫자 표가 아니라 공간을 통째로 움직이는 기계 — 열이 축을 어디로 옮기는지 보고, 늘리기·돌리기·밀기·납작(특이)을 격자와 집 그림으로 체험하며, 순서를 바꾸면 결과가 달라지는 것, 역행렬로 되돌리기, 행렬식, 행렬 암호(DATA → 9 5 41 21)까지 손으로 해 보는 앱입니다. 선형대수 03 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 기계: 예시·늘리기·돌리기·밀기·납작·직접 입력 행렬로 격자 변환 애니메이션, 행렬식과 넓이 변화, 열로 보는 행렬 곱
- ② 순서: 밀고→돌리기 vs 돌리고→밀기 비교, 퀴즈 ①
- ③ 되돌리기: 역행렬로 되돌리는 애니메이션, 특이 행렬에서 두 점이 한 점으로, 퀴즈 ②, (AB)⁻¹ = B⁻¹A⁻¹
- ④ 암호: 단어를 행렬로 암호화·복호화(행렬식 0인 열쇠의 문제점 포함), 한꺼번에 계산하는 속도 예시, 행렬로 되는 편집 기능 분류, 세 줄 정리
